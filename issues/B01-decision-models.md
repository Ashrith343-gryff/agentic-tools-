# B01 — Decision Models & Contracts

## Goal
Create the core decision data models and public contracts.

## Implement models for:
- `Decision`
- `ToolCandidate`
- `ToolSelection`
- `AgentRoute`
- `Handoff`

## Decision values:
- `call_tool`
- `no_tool`
- `cannot_decide`

## Requirements:
- typed models
- deterministic serialization
- validation
- JSON schemas
- tests
- no external API
